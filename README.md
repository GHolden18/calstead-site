# calstead-site

The website for Calstead Studios LLC, served at https://calsteadstudios.com by GitHub Pages.

Plain HTML and CSS, no build step. `index.html` is the home page; `fatside/privacy/` and
`fatside/terms/` are Fatside's legal pages (kept in step with `src/data/legal.ts` in the
Fatside repo); `assets/site.css` is the one stylesheet. `CNAME` holds the domain.
